                          Regeln

                          Wünschen und abstimmen können alle Nutzer mit dem Feature „Musik (Spotify)“. Admins dürfen immer alles.

                          Steam-API-Schlüssel

                          Den Schlüssel bekommst du kostenlos unter steamcommunity.com/dev/apikey (als Domain einfach „lanparty“ eintragen). Er bleibt auf dem Pi und wird nie an Browser geschickt.

                          Steam-Profile der Nutzer

                          Nutzer mit dem Feature „Spiele-Matrix“ können ihr Profil auch selbst im Dashboard verknüpfen. Eintragen kannst du einen Profil-Link, den Namen aus der Profil-URL oder die SteamID64. Feld leeren und speichern trennt das Profil.
